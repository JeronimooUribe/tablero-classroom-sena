# Tablero del proyecto de grado

Mapa navegable para estudiar y exponer el proyecto de grado (media técnica articulada con el SENA): 16 esferas del porqué al cómo, guía para exponer, plan de estudio y prompts para NotebookLM.

Todo el contenido vive en `data.js`. Sitio estático, sin dependencias de construcción.
